## Platform
web

Responsive desktop and mobile. Next.js App Router, React and TypeScript. Existing stack retained.

## Purpose and users
Hackathon Checkpoint 1 concept: three security agents connect upstream risk, repair and local verification. The Supply Chain Agent matches inventory to advisories and compromise alerts. The Remediation Agent proposes supported updates and code repairs. The Development Security Agent watches local changes, establishes baseline checks, and verifies candidate repairs with scoped security tests and legitimate-use controls. A deterministic controller routes work; an evidence gate and human reviewer govern promotion. Small TypeScript SaaS teams remain the initial customer hypothesis.

## Confirmed scope
Four team members. Judging weights: problem 35%, idea 30%, business 25%, development 10%. User requested stronger frontend and presentation, Bklit components, Impeccable, Anthropic skills and Anatomy. User selected dark engineering workspace plus an isometric machine on 24 October 2026.

Incident/configuration follow-up prevents draft eligibility even when the five represented checks pass. Agent runs reset on leaving this view; existing per-finding state persists locally.
